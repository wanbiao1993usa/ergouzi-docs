## 这篇内容适合谁

注册赠送$0.5体验额度，0.02倍率下实际可用$25，体验后想购买额度，按量使用，那么这篇就是你应该走的路线。

这条路径对应的是：

- 先准备普通余额
- 后续调用按量扣费
- 适合先试用、用量不稳定、或者希望控制成本的人

> 如果你要买的是无限订阅套餐，直接去看 [购买无限订阅](/guides/subscription)。

## 购买流程概览

这条路径可以压缩成五步：

1. 注册并登录账号
2. 进入钱包管理
3. 点击购买兑换码
4. 会跳转到某淘购买链接
5. 目前只有￥36.5的商品，对应余额$5，0.02倍率计算后实际可用$250
4. 拍下商品，自动发货兑换码
5. 回到钱包页，输入兑换码，完成兑换

## 第一步：注册账号并登录

先完成账号注册，然后登录到二狗控制台。

只有在登录状态下，你才能：

- 进入钱包管理页面
- 购买兑换码
- 后续完成兑换

## 第二步：进入钱包管理，然后点击购买兑换码

登录后进入钱包管理页面，在“兑换码充值”区域找到 **购买兑换码**。

这一步的作用，是从你自己的账号后台跳转到购买页。  

![钱包管理页中的购买兑换码入口](/assets/purchase/step1.png)

## 第三步：在某淘购买商品

跳转到某淘后，找到你要购买的商品，并按你需要的数量下单。

这里最重要的是两点：

- 商品名称要以购买页面实际显示为准
- 购买数量要和你自己需要的额度对应

如果你在截图、聊天记录或口头描述里看到的名称和页面显示略有不同，以页面显示为准。

![某淘的商品购买页面](/assets/purchase/step2.png)

## 第四步：拿到兑换码

购买成功后，你会在订单消息或聊天消息里收到一串兑换码。

这里最容易出错的是复制环节，所以请注意：

- 要复制完整
- 不要漏字符
- 不要多复制空格
- 不要手动改动内容

![聊天消息中的兑换码](/assets/purchase/step3.png)

## 第五步：回到钱包页进行兑换

拿到兑换码后，回到钱包管理页面，在“兑换码充值”的输入框里粘贴刚才复制的内容，然后点击 **兑换额度**。

这一步完成后，额度才会真正进入你的账号。

![在钱包管理页输入兑换码并点击兑换额度](/assets/purchase/step4.png)

## 这条流程最常见的错误

如果你在这里遇到问题，优先检查下面几项：

- 商品名称是不是看错了，是否和购买页实际商品一致
- 兑换码是否复制完整
- 是否带了多余空格
- 是否已经重复兑换过
- 如果付款成功但没收到兑换码，先回订单消息或联系商家确认发码状态

## 兑换完成后下一步做什么

如果你已经把额度充进账号，下一步通常是：

1. 先理解 Token 和分组关系  
   去看 [账号与 Token 基础说明](/guides/token-billing)

2. 再创建真正用于调用的 Token  
   去看 [创建 API Token](/guides/token)
3. 或者直接去看 [CC Switch 配置教程](/apps/cc-switch)

## 一句话总结

这条路的本质是：

**购买商品 -> 拿到兑换码 -> 把兑换码换成账号里的普通余额。**

余额到位之后，才适合继续进入 Token 创建和 API / 客户端接入步骤。
