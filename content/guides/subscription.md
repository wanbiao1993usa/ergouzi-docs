## 这篇内容适合谁

如果你不是想先充普通余额，而是准备直接买 **无限订阅**，这篇就是你应该走的路线。

它适合：

- 想直接开通订阅权益
- 不想先走普通余额兑换流程
- 已经确定自己的使用方式更适合订阅套餐

> 如果你只是想先充值普通额度，别混着看这篇，直接去看 [购买普通余额兑换码](/guides/purchase)。

## 先记住这条路线的关键区别

无限订阅和普通余额最大的区别不是“入口长得不一样”，而是：

- 普通余额：买完兑换码后，自己回到钱包页兑换
- 无限订阅：买完后还要把 **用户名发给客服**，由客服手动开通

也就是说，订阅并不是“付款完成就自动生效”的路线。

## 购买流程概览

这条路径可以压缩成三步：

1. 注册并登录账号
2. 在账户充值页购买无限订阅套餐
3. 把当前账号的用户名发给客服，由客服手动开通

理解这三步之后，整条流程其实很直接。

## 第一步：注册账号并登录

先完成账号注册，然后登录到二狗控制台。

只有登录之后，你才能：

- 进入账户充值页
- 购买无限订阅套餐
- 后续确认订阅是否已经成功生效

如果你还没有账号，先去完成注册；  
如果已经有账号，直接登录即可。

## 第二步：进入账户充值页，购买无限订阅套餐

登录后进入账户充值页面，点击 **购买无限流量套餐**，进入购买流程。

这一步只是完成付款，不代表订阅已经自动写进你的账号。

所以这一步做完后，不要立刻把“支付成功”和“订阅开通成功”划等号。

![账户充值页中的购买无限流量套餐入口](/assets/purchase/subscription-step1.png)

## 第三步：把用户名发给客服，由客服手动开通

购买完成后，你需要把 **当前登录账号的用户名** 发送给客服。

这里要特别注意三点：

- 发的是 **用户名**
- 不是密码
- 也不是 API Token

客服会根据这个用户名，手动把订阅权益加到对应账号上。  
只有客服处理完成后，订阅才算真正生效。

## 这一步为什么容易出错

订阅路线最常见的问题，不是支付失败，而是“发错信息”或者“以为系统会自动开通”。

最容易出错的情况包括：

- 发给客服的是错误账号的用户名
- 发的是 Token，不是用户名
- 付款后就直接去客户端测试，没有先确认客服是否已处理完成

所以更稳的做法是：

1. 支付完成
2. 把当前购买账号的用户名发给客服
3. 等客服确认
4. 再回到账号页检查订阅状态

## 订阅开通后下一步做什么

订阅开通成功后，你后面真正调用客户端、SDK 或 API 时，依然需要 Token。

也就是说，订阅路线走完后，下一步通常是：

1. 先确认自己理解 Token 和权益的关系  
   看 [账号与 Token 基础说明](/guides/token-billing)

2. 再创建真正用于调用的 Token  
   看 [创建 API Token](/guides/token)

## 常见注意事项

- 如果你只想按额度充值，请改看 [购买普通余额兑换码](/guides/purchase)
- 如果已经付款但订阅没有生效，先确认用户名是否已经正确发给客服
- 一定要确认发给客服的是当前购买账号的用户名，避免把订阅加到错误账号上

## 一句话总结

这条路线的本质是：

**购买订阅套餐 -> 把用户名发给客服 -> 等客服手动开通。**

只有客服处理完成后，订阅才算真正生效。
